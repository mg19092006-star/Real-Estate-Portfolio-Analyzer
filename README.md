# Real Estate Portfolio & Property Investment Analyzer

An analytics project that uses Microsoft Excel for data preparation and financial calculations and Microsoft Power BI for interactive real-estate portfolio dashboards.

## Project overview

The project brings together property details, rental income, maintenance expenses, and financial analysis to help explore portfolio valuation, operating performance, investment returns, and costs.

## Files in this repository

- `Real_Estate_Portfolio_Data.xlsx` — Excel workbook with four worksheets:
  - Property Master
  - Rental Income Table
  - Maintenance Expenses
  - Property Financial Analysis
- `Real_Estate_Portfolio_Dashboard.pbix` — Power BI report containing the dashboard pages.

## Tools used

- Microsoft Excel
- Microsoft Power BI Desktop
- Data cleaning and preparation
- Financial analysis and data visualization

## How to use

1. Download or clone this repository.
2. Open `Real_Estate_Portfolio_Data.xlsx` in Microsoft Excel to inspect the worksheets and data.
3. Open `Real_Estate_Portfolio_Dashboard.pbix` in Power BI Desktop to explore the report.
4. Use the report's available slicers and filters to explore the visuals interactively.

## Main analysis areas

- Portfolio overview and property values
- Investment and geographical distribution
- Acquisitions and maintenance expenses
- Financial trends and vendors
- Property performance and valuation

## Data note

The project synopsis and presentation describe the dataset as AI-generated. Figures and findings in the report should therefore be treated as project/demo data, not verified live market information.

## Authoring context

Prepared as a student analytics project for exploring real-estate portfolio data using Excel and Power BI.
